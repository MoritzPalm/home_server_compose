About

What I work on

I'm a master's student in computer science. My thesis is about segmenting videofluoroscopic swallowing studies, the X-ray videos clinicians record to see how a person swallows. The models are multimodal: they draw on more than one kind of input to outline the anatomy and the bolus in every frame, so that swallowing disorders can be measured rather than eyeballed.

The other half of my time goes into a home server that I treat as a small production system. Ansible provisions the host, every service is a Docker Compose stack in a public repository, traffic enters through a Cloudflare Tunnel and Traefik, and dependency updates arrive as pull requests. Decision records and runbooks live next to the code, because future me is the on-call.

Before that: coursework and side projects in machine learning, from LiDAR object detection to generating MNIST digits with kernel density estimation. All of it is on GitHub.

  2. Home server

    Since 2025

    A home server, run like production

    Twenty-odd self-hosted services on one machine: photos, documents, books, media, recipes and a few tools of my own. Traefik routes everything behind a Cloudflare Tunnel, CrowdSec screens requests, Authentik handles sign-in, and a Raspberry Pi watches from outside the network.

    Renovate opens the update pull requests, tiered by how much damage a bad release could do. Postgres never auto-merges; a stateless patch does.
